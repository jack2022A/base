# LivreNKI Leve para Windows

Baixe `LivreNKI-Leve-Windows.zip`, extraia todo o conteúdo e dê duplo clique
em `Iniciar-LivreNKI.bat`. O BAT e o executável precisam permanecer juntos na
mesma pasta. O programa funciona no Windows 10 ou 11 de 64 bits.

Para quem já baixou a versão anterior, `Iniciar-LivreNKI-BAT.zip` contém
somente o novo arquivo BAT.

O LivreNKI cataloga pastas de instrumentos `.nki`, oferece busca e abre o
timbre selecionado no aplicativo associado pelo Windows. O Kontakt precisa
estar instalado e associado à extensão `.nki`.
