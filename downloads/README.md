# LivreNKI Leve para Windows

Baixe `LivreNKI-Leve-Windows.zip`, extraia o conteúdo e execute
`LivreNKI-Leve.exe` no Windows 10 ou 11 de 64 bits.

O LivreNKI cataloga pastas de instrumentos `.nki`, oferece busca e abre o
timbre selecionado no aplicativo associado pelo Windows. O Kontakt precisa
estar instalado e associado à extensão `.nki`.
